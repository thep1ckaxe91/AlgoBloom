# T14 — Hoàn thành MVP và kiểm thử tích hợp

**Người phụ trách:** Long (`@LongSei`).

**Trạng thái:** Nhánh chuẩn bị. Checklist chưa chọn là việc chưa có bằng chứng hoàn thành.

## Yêu cầu mốc
T14 phải có MVP hoàn chỉnh, code tích hợp, OpenAPI/README khớp code, automated tests và môi trường demo tái hiện. Demo một use case hoàn chỉnh, request thành công/lỗi, chạy một phần test suite và giải thích API design pattern đã triển khai.

## Checklist Long
- [ ] Cập nhật nhánh theo main sau khi code T13 được review/merge; không tự copy đè phần Gateway/Judge.
- [ ] Khắc phục lỗi integration/schema drift; sinh đề qua verification hiện có và phân tích submission với timings thật.
- [ ] Kiểm tra generator nhận N/seed và 4 tiers; xác nhận lỗi code sinh ra được báo rõ thay vì giả thành công.
- [ ] Chuẩn hóa lỗi input/auth/upstream/invalid output; logging có request/job correlation và bỏ secret.
- [ ] Unit test business logic quan trọng; integration/API tests happy path, validation, unauthorized/forbidden ở boundary tương ứng, failure cases và regression.
- [ ] Chạy full-stack bằng môi trường cấu hình/seed tái hiện; README có lệnh chạy/test/reset và phương án demo khi quota/mạng lỗi.
- [ ] Phối hợp giải thích async job orchestration (202 + polling) hoặc pattern thật đã triển khai; không gọi sơ đồ thiết kế là bằng chứng code.
- [ ] Báo số test pass/fail/skipped, coverage nếu đo, lỗi sửa và giới hạn còn lại; lưu output gắn commit.
- [ ] Đóng băng MVP sau khi đủ evidence; đóng góp báo cáo 1–2 trang và slide nhóm 7–10 trang.

## Phạm vi
MVP đã cam kết là bắt buộc. Agent loop, kho tái sử dụng, held-out evaluation, calibration/adaptive learning và nghiên cứu không được lấn thời gian sửa MVP. Chỉ nối P1 khi MVP đã đạt và còn thời gian; giữ DoD riêng.

## Phụ thuộc
#11/#12 đã có code; Khánh/Nam/Sơn hoàn thành phần tích hợp. AI Service vẫn stateless; persistence và auth public thuộc Gateway. Review trước publication của P1 không được tự tuyên bố đã có ở P0.

## Bằng chứng bàn giao
MVP runbook, automated test report, bug fixes, API examples thực tế, Docker/full-stack demo và phần đóng góp Long. Hiện nhánh chỉ có kế hoạch, chưa có bằng chứng MVP hoàn thành.
